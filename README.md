Respuesta al reto:

Aplicaciones: TikTok, Instagram Reels, YouTube Shorts

1. ¿Qué estructura de datos creo que usa internamente?
Creo que utilizan principalmente listas enlazadas y arreglos, además de otras estructuras más avanzadas que desconozco.

2. ¿Por qué esa y no otra?
Porque necesitan manejar grandes cantidades de videos y datos de usuarios. Los arreglos pueden servir para organizar y acceder rápidamente a elementos, mientras que las listas enlazadas pueden facilitar el manejo de elementos que se agregan o eliminan constantemente. Por ejemplo, los videos que aparecen en el feed podrían organizarse de manera que sea fácil cambiar el contenido que se muestra al usuario.
